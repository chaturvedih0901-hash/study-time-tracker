# Problem Statement & Scope: Study Time Tracker

## Problem Statement
Students often struggle to maintain a consistent record of their actual study hours. Manual tracking is tedious, repetitive, and frequently leads to inaccurate or incomplete logs. Without organized and automated time-tracking data, evaluating productivity across different subjects and comparing daily focus levels becomes difficult. A lightweight, reliable tool is needed to transform individual study sessions into actionable productivity insights.

## Project Objectives
- **Session Tracking:** Enable students to log real-time study sessions with subject and topic details.
- **Automated Duration Calculation:** Automatically compute time spent during each session using timestamping.
- **Persistent Data Storage:** Store study history reliably in JSON format so data persists across application runs.
- **Goal Management:** Allow users to set, update, and monitor daily study targets in minutes.
- **Productivity Analytics:** Generate daily, subject-wise, and 7-day weekly progress reports.
- **Modular Architecture:** Build a maintainable and structured Python console application with built-in unit tests.

## Scope of the Project
- **Target Audience:** Individual students aiming to record, analyze, and optimize their study habits.
- **Current Deliverables:** Single-user CLI application featuring session execution, analytics reporting, unit testing, and JSON file persistence.
- **Out of Scope:** Cloud database synchronization, multi-user authentication, web interface, and mobile app support.
